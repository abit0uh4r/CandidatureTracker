# Parcours de démonstration

Durée cible : 3 minutes.

## Préparation avant la soutenance

1. Lancer le serveur Laravel.
2. Lancer Vite si nécessaire.
3. Préparer un compte utilisateur de démonstration.
4. Préparer une candidature existante pour montrer la liste.
5. Vérifier que Debugbar est actif en local.
6. Répéter le parcours au moins deux fois.

Commandes utiles :

```powershell
php artisan serve
npm run dev
```

## Parcours à suivre

1. Ouvrir l'application.
2. Se connecter.
3. Ouvrir la page `Candidatures`.
4. Cliquer sur `Nouvelle candidature`.
5. Créer une candidature :
   - entreprise : Maroc Telecom
   - poste : Développeur Laravel Junior
   - statut : Candidature envoyée
   - priorité : Haute
   - date : date du jour
6. Ouvrir le détail de la candidature.
7. Ajouter un entretien :
   - type : Entretien RH
   - date : demain matin
   - notes : Préparer le parcours et les motivations
8. Montrer la section documents si elle est disponible.
9. Ouvrir Debugbar rapidement pour montrer les requêtes.
10. Archiver la candidature.
11. Aller dans `Archives`.
12. Restaurer la candidature.
13. Revenir à la liste principale.

## Phrase de transition

```text
Cette démonstration montre le parcours principal : de la création d'une opportunité jusqu'à son archivage et sa restauration.
```
