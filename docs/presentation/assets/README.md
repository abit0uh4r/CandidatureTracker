# Captures à placer ici

Ces fichiers ne sont pas générés automatiquement, car la soutenance demande des captures réelles ou issues d'outils dédiés.

À ajouter avant de finaliser les slides :

- `dashboard.png` : capture réelle du dashboard ou de la liste des candidatures.
- `mcd.png` : export du MCD depuis draw.io, Lucidchart ou un outil Merise équivalent.
- `mld.png` : export du MLD depuis dbdiagram.io, draw.io ou équivalent.
- `jira-board.png` : capture du board Jira pendant le développement, avec des tickets dans plusieurs colonnes.
- `github-qr.png` : QR code optionnel vers le dépôt GitHub.

Règle importante : le MCD et le MLD doivent venir d'un outil de modélisation, pas d'une capture improvisée.
